Confirmer votre adresse

Un destinataire a demandé une confirmation pour un envoi placé en quarantaine. Continuez uniquement si vous avez envoyé ce message.

Lettres et chiffres, sans les caractères I, O, 0 et 1. Code valable au maximum dix minutes.

Si vous ne pouvez pas lire le code, contactez le destinataire : il peut libérer manuellement cet envoi depuis sa console.

Cette confirmation vérifie l’accès à votre boîte. Elle ne prouve pas que vous êtes humain ni que le message est sûr. Les prochains messages restent filtrés.
